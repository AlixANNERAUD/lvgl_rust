# Use external fonts

This guide compiles fonts made with `lv_font_conv` in a crate of their
own, so that editing a font never recompiles LVGL, and uses them from
lvgl-rust. It also covers the legacy `LVGL_FONTS_DIR` mode.

## What you need

- Font sources generated by `lv_font_conv --format lvgl`, one `.c` file
  per font. Give each one a unique `--lv-font-name` (for example
  `font_montserrat_14_latin` and `font_montserrat_14_cjk`) so several
  profiles can sit in one firmware.
- An application that depends on lvgl-rust (or `lvgl-rust-sys`).

## Steps

### 1. Create the font crate

The font crate depends on `lvgl-rust-sys` directly: only direct
dependents' build scripts receive its exported metadata.

```toml
# fonts/Cargo.toml
[package]
name = "my-fonts"
version = "0.1.0"
edition = "2024"
build = "build.rs"

[dependencies]
lvgl-rust-sys = { git = "https://github.com/AlixANNERAUD/lvgl_rust", default-features = false }
# For `&'static Font` (step 3); a crate that stays raw leaves it out.
lvgl-rust = { git = "https://github.com/AlixANNERAUD/lvgl_rust", default-features = false }

[build-dependencies]
cc = "1.1.18"
```

`default-features = false` keeps the crate from turning features of
`lvgl-rust-sys` back on (`use-string-functions`, ...); lvgl-rust enables
what it needs itself.

### 2. Compile the fonts with LVGL's exact configuration

`lvgl-rust-sys` exports its build configuration through `links =
"lvgl_rust_sys"`:

| Variable | Content |
| --- | --- |
| `DEP_LVGL_RUST_SYS_INCLUDE_PATHS` | `;`-separated include directories (LVGL, your `lv_conf.h`, shims) |
| `DEP_LVGL_RUST_SYS_DEFINES` | `;`-separated `NAME` or `NAME=VALUE` definitions (configuration, color depth) |
| `DEP_LVGL_RUST_SYS_CFLAGS` | `,`-separated `LVGL_CFLAGS` entries |
| `DEP_LVGL_RUST_SYS_TARGET` | the Cargo target of the native build |

A build script that uses all four, adapted from
[`lvgl-rust-sys/examples/external-fonts/build.rs`](../../lvgl-rust-sys/examples/external-fonts/build.rs):

```rust
// fonts/build.rs
use std::{env, fs, path::PathBuf};

fn define(build: &mut cc::Build, entry: &str) {
    let (name, value) = entry
        .split_once('=')
        .map_or((entry, None), |(name, value)| (name, Some(value)));
    build.define(name, value);
}

fn main() {
    let var = |name: &str| env::var(name).unwrap_or_else(|_| panic!("{name} is not set"));
    let mut build = cc::Build::new();
    build.target(&var("DEP_LVGL_RUST_SYS_TARGET")).warnings(true);
    for path in var("DEP_LVGL_RUST_SYS_INCLUDE_PATHS").split(';').filter(|p| !p.is_empty()) {
        build.include(PathBuf::from(path));
    }
    for entry in var("DEP_LVGL_RUST_SYS_DEFINES").split(';').filter(|d| !d.is_empty()) {
        define(&mut build, entry);
    }
    for entry in var("DEP_LVGL_RUST_SYS_CFLAGS").split(',').filter(|d| !d.is_empty()) {
        define(&mut build, entry);
    }
    let fonts = PathBuf::from(var("CARGO_MANIFEST_DIR")).join("sources");
    println!("cargo:rerun-if-changed={}", fonts.display());
    for entry in fs::read_dir(&fonts).unwrap() {
        let path = entry.unwrap().path();
        if path.extension().is_some_and(|extension| extension == "c") {
            println!("cargo:rerun-if-changed={}", path.display());
            build.file(path);
        }
    }
    build.compile("my_fonts");
}
```

Use `cc`, which is target-aware (it honours `CC_<target>` and
`CFLAGS_<target>`), and the exported definitions: do not substitute the
host target or guess ABI-affecting definitions yourself.

### 3. Expose the fonts as `&'static Font`

Each font is an `lv_font_t` defined by the C file. Declare it and wrap it
in lvgl-rust's `Font`:

```rust
// fonts/src/lib.rs
#![no_std]

use lvgl_rust::{Font, sys::lv_font_t};

unsafe extern "C" {
    static font_montserrat_14_latin: lv_font_t;
    static font_montserrat_14_cjk: lv_font_t;
}

pub const fn latin() -> &'static Font {
    // SAFETY: a constant font compiled with LVGL's configuration; nothing
    // writes to it.
    unsafe { Font::from_raw(&*(&raw const font_montserrat_14_latin)) }
}

pub const fn cjk() -> &'static Font {
    // SAFETY: as above.
    unsafe { Font::from_raw(&*(&raw const font_montserrat_14_cjk)) }
}
```

This needs the `lvgl-rust` dependency of step 1. A crate that uses
only `lvgl-rust-sys` returns `*const lv_font_t` instead (`&raw const
font_montserrat_14_latin`), as the example does.

`Font::from_raw` is `unsafe`: the font must be a valid LVGL font usable
from any thread holding the lock, and nothing may write to it afterwards.
Fonts that change at run time (`tiny_ttf` fonts after
`lv_tiny_ttf_set_size`) stay raw.

### 4. Use the fonts

In a constant style, kept in flash:

```rust
use lvgl_rust::{ConstStyle, color, const_style};

static BODY: ConstStyle = const_style![
    text_font(my_fonts::latin()),
    text_color(color::hex(0x202020)),
];
```

or on one object, with exclusive access:

```rust
use lvgl_rust::Selector;

let mut title = title_handle.get_mut(&mut lv)?;
title.set_style_text_font(my_fonts::cjk(), Selector::DEFAULT);
```

or in a mutable `Style` through `lv.style(&STYLE).set_text_font(font)`.
Switching languages is then a matter of choosing another `&'static Font`.

### 5. Or keep fonts inside LVGL's build (legacy `LVGL_FONTS_DIR`)

Set `LVGL_FONTS_DIR` to a directory: its `.c` files are compiled into the
LVGL archive and its top-level headers are passed to bindgen. Any font
change rebuilds LVGL and regenerates the bindings. Fonts declared in those
headers (`LV_FONT_DECLARE(my_font_16)`) appear in `lvgl_rust::sys`, and
lvgl-rust generates a `const` constructor for each `lv_font_t` static of
the bindings, with an `lv_font_` prefix removed: `Font::montserrat_14()`
for LVGL's own `lv_font_montserrat_14`, `Font::my_font_16()` for
`my_font_16`.

The mode is opt-in: a `fonts/` directory in the working directory is not
picked up unless `LVGL_FONTS_DIR` names it.

## Pitfalls

- **Unique names.** Two profiles with the same `--lv-font-name` define the
  same symbol twice and fail to link.
- **Rebuild triggers.** Print `cargo:rerun-if-changed` for the font
  directory and every source, or edits will not rebuild the font crate.
- **Fonts stay in flash.** Descriptors and glyph tables are `const` data.
  Position-independent host executables may put pointer-bearing
  descriptors in `.data.rel.ro`; on embedded targets check the placement
  in your map file.
- **LVGL keeps pointers to fonts**, which is why lvgl-rust only accepts
  `&'static Font`.
