# lvgl-rust documentation

User documentation of `lvgl-rust`, the safe `no_std` bindings for LVGL 9,
and of `lvgl-rust-sys`, the raw bindings it builds on. The pages follow
the [Diátaxis](https://diataxis.fr) structure:

- **Tutorials** teach by doing: follow one from start to finish.
- **How-to guides** reach one goal, in steps, for readers who know what
  they want.
- **Explanation** says why the crate works the way it does.
- **Reference** describes each item, input and number, to look up.

The API documentation of each item is on
[docs.rs](https://docs.rs/lvgl-rust). The architecture and the rules for
changes are in [`AGENTS.md`](../AGENTS.md).
